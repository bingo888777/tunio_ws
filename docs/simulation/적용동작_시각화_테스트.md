# 적용 동작 시각화 테스트

PR #110 생성 후 추가한 로봇 연결 없는 테스트 코드입니다. ROS 노드·두산 이동 API는
실행하지 않습니다. `motion_primitives._pick_to_peg_approach`와
`_transfer_above_floor`를 그대로 호출하고, IK/현재값/이동 명령만 수치 대역으로 바꿉니다.
코드의 최신 YAML 경유점을 읽으며 화면에서 경로를 임의 편집하지 않습니다.

## 실행

```bash
cd /home/mook/tunio_ws
# 최초 1회 또는 fcl 의존성이 없을 때. /tmp 대신 지속되는 가상환경 사용.
bash tools/setup_zone_motion.sh

# 오른쪽→왼쪽 6번 전환: 높은 접근점까지
OPENBLAS_NUM_THREADS=1 .venv-zone/bin/python tools/work_motion_test.py --high-only

# 하강까지 포함해서 보기. 첫 충돌 위치로 이동
OPENBLAS_NUM_THREADS=1 .venv-zone/bin/python tools/work_motion_test.py --first-hit

# 5번, 대기 자세 출발
OPENBLAS_NUM_THREADS=1 .venv-zone/bin/python tools/work_motion_test.py --peg 5 --start standby --high-only

# 고정 홈 없이 왼쪽 자세를 유지하는 거치대→발현 상단
OPENBLAS_NUM_THREADS=1 .venv-zone/bin/python tools/work_motion_test.py --scene holder-to-pluck --side left --peg 6

# 발현 상단→거치대 상단 / 페그 앞→거치대 상단
OPENBLAS_NUM_THREADS=1 .venv-zone/bin/python tools/work_motion_test.py --scene pluck-to-holder --side left
OPENBLAS_NUM_THREADS=1 .venv-zone/bin/python tools/work_motion_test.py --scene peg-to-holder --peg 6

# 창 없이 충돌 검사/JSON 기록. 충돌·TCP 미확정·관절 오류는 종료 코드 1.
OPENBLAS_NUM_THREADS=1 .venv-zone/bin/python tools/work_motion_test.py --check --output /tmp/work-motion.json
```

`--peg 6/5/2/1`, `--side right/left`로 같은 쪽 이동을 고릅니다.
새 `transition`은 6·5번만 지원합니다. 반대 방향 전환은 구현/시험 대상에서 제외했습니다.
`--model`로 M0609/SRDF/RG2 설치 경로 JSON을 지정할 수 있습니다.
기본 `work_motion_model.json`은 현재 PC의 외부 드라이버 설치 경로입니다.
드라이버나 메시 원본은 저장소에 복사하지 않습니다.

재생·일시정지, 시간 슬라이더, 첫 충돌 이동, 마우스 회전·확대를 제공합니다.
메시는 GPU에 한 번 올리고 재생 중에는 변환 행렬만 갱신합니다. 경로/충돌 검사도
최초 한 번 수행하므로 재생 프레임마다 CPU 검사를 반복하지 않습니다.
10fps 재생은 보기 위한 시간축이며 실제 로봇 소요 시간과 다릅니다.

## 실제 검사 결과와 알려진 충돌

0.5도 관절 표본, RG2 폭 38mm, 수치 IK 기준입니다.

- 6·5번의 거치대 상단/standby 출발→높은 접근점 4경로는 박스·자기 충돌/TCP 침범 없음.
- 거치대 상단↔발현 상단, 4개 줄×좌/우 자세×양방향 16경로도 충돌/TCP 침범 없음.
- **6·5번 전환에서 마지막 하강을 포함하면 RG2와 TCP가 빨간 박스를 침범합니다.**
  6번은 약 Z=237mm에서 RG2가 먼저 닿고, TCP는 Z=200 아래에서 침범합니다.
  6번 접근 끝점은 약 `[336.04, -175.18, 112.62]mm`로 박스 내부입니다.
- 페그 앞→거치대 상단도 네 줄 모두 시작/상승 구간이 박스 내부입니다.
  높이 이동 구간의 통과와 기존 낮은 작업 좌표의 통과를 혼동하면 안 됩니다.
- 위 26경로에서 자기 충돌은 없었습니다. 박스와 기존 접근 좌표가 겹치는 문제는
  해결된 상태가 아닙니다. 박스/교시점을 임의 수정하거나 충돌 검사를 제외하지 않았습니다.

원자료는 `work_motion_checks.json`입니다. 원자료의 표본 수는 공통 끝점 중복을
제거하므로 초기 문서의 구간별 집계와 몇 개 차이 납니다.

## 한계

수치 IK에서 2/7이라는 이름은 시작 해 탐색용 대역입니다. 공식 두산 sol 번호를
검증하지 않습니다. 관절 이동은 선형 표본, movel은 자세를 유지한 3mm 간격 수치 IK로
근사합니다. 컨트롤러 블렌딩/특이점/속도 프로파일을 재현하지 않습니다.

표시·검사는 M0609와 RG2 충돌 메시 전체를 사용하되, 골무·피크·케이블과 박스 밖
기타 목/헤드/이웃 페그는 제외됩니다. 메시 표본 사이 연속 충돌을 보증하지 않습니다.
거치대 집기·삽입, 실제 발현 스트로크, 페그 파지·회전까지 재현하는 통합 시험은 아닙니다.

버튼/렌더링 자동 검사는 `tools/work_motion_test.py --high-only --ui-check`로 실행합니다.
