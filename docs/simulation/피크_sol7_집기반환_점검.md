# sol 7 피크 집기·반환 단독 시험

사용자가 조회한 거치대 위 IK에서 sol 7은 J1 +166.93°, J4 -0.05°, J5 -102.50°다.
6·5번용 후보이며 아직 실기 경로가 확인된 것은 아니다. sol_check의 '음수=왼쪽' 문구는
현재 작업 구역 기준과 맞지 않는다. 현재 6·5번 J1 범위는 +100~240°다.

두산 드라이버만 켜고 robot_controller와 다른 로봇 이동 프로그램은 종료한다.
피크는 거치대, 그리퍼는 빈손 상태에서 시작한다. 작업자가 초기 자세부터의 회전 공간을
확인한다. 프로그램의 노드 이름 검사는 다른 모든 명령원을 잠그는 기능이 아니다.

```bash
cd ~/tunio_ws
source /opt/ros/jazzy/setup.bash
source install/setup.bash
python3 tools/pick_cycle_check.py --sol 7
python3 tools/pick_cycle_check.py --sol 7 --execute
```

첫 명령은 계획만 출력한다. 실행 명령에서 START를 입력하면 연결/TCP 설정 후 IK를
검사하고, 각 단계 전에 Enter를 받아 다음 동작을 수행한다. 다른 글자를 입력하면 중단한다.

1. 필요 시 기존 J1 경유점으로 이동(별도 확인).
2. sol 7로 거치대 위 접근, 실제 sol과 TCP 위치 확인.
3. 그리퍼 열기.
4. 수직 하강 후 집기 위치 확인.
5. 피크 집기, 설정된 파지 대기시간 적용.
6. 피크를 든 채 수직 상승.
7. 수직 하강 후 반환 위치 확인.
8. 피크 놓기.
9. 빈손 상승 후 도달 확인.

관절 이동은 5도/초·가속도 10도/초² 설정(기존 손끝 속도 제한 유지), 수직 이동은
10mm/초·20mm/초²다. YAML은 덮어쓰지 않는다. 발현·페그 조절·J6 회복은 하지 않는다.
J6 여유가 없으면 중단한다. 운영의 J6 대칭 자세 선택 함수를 지정 sol로 사용한다.
관절 목표의 J1/J6를 검사하나 실제 중간 경로 전체의 충돌을 인증하는 도구는 아니다.

중단 시 자동 개방/복귀하지 않는다. 피크를 들고 중단했다면 그대로 든 상태일 수 있다.
Ctrl+C는 로봇 정지 명령이 아니다. 실행 기록은 ~/.tunio/robot_data/*_pick_cycle_check.json.
집기 성공은 자동 감지하지 않으므로 작업자가 확인한다.

통과 후 결과를 바탕으로 sol_by_side.left=7을 운영 설정에 적용하고 발현까지 연결한다.
이번 도구 추가만으로 운영 설정을 확정하거나 실기 성공으로 기록하지 않는다.
