## 확인한 정책

검사 시점은 집기 닫힘 안정화 후 들어 올리기 전, 타현 후 후퇴한 뒤,
일시정지 후 피크가 필요한 동작을 재개하며 피크를 들고 있던 경우다.

- 빈손: 감지 이후 거치대에서 추가 집기 최대 2회. 성공하면 계속한다.
- 두 번 모두 실제 빈손: 관제 알림 → 로봇 내부 홈 복귀 → 실패 Result → 서버 작업 중단.
- 폭 읽기 실패: 한 번 재읽기, 계속 실패하면 관제에 폭 확인 불가를 알리고 진행한다.
- 재집기 중 읽기 실패도 빈손 실패 횟수로 취급하지 않는다.
- 페그 파지·피크 반환 상태에 피크 문턱을 적용하지 않는다.
- 반환 위치 읽기 실패나 수직 후퇴 이동 거부를 빈손으로 바꾸지 않는다.
  상태를 모름으로 유지하고 추가 이동·집기·홈 이동을 하지 않는다.
- 정상 피크 상태는 관제 알림을 만들지 않는다. 읽기 실패 경고는 Action 성공과 공존한다.
