판정은 센트로 하고 화면 표시는 Hz 다. 오차가 양수면 목표보다 높은 음이다.

줄별 결과

최신순으로 최근 20건까지 보여준다.

왼쪽에서 작업을 고르면 줄별 기록과 그때 적용된 설정을 보여준다.

변경 가능

센트 오차의 절댓값이 이 값 이내면 성공으로 본다. 0보다 커야 한다.

줄당 페그 조절 상한. 0이면 조절하지 않고 측정만 한다.

측정이 실패했을 때 페그를 돌리지 않고 다시 튕기는 상한.

녹음 길이가 아니라 응답 제한이다. onset 검출 시점부터 센다.

이 안에 소리가 들어오지 않으면 '소리 부족'으로 처리한다.

목표 주파수는 화면에서 바꾸지 않는다(A4=440Hz, 12평균율 고정). 작업이 진행 중이면 설정은 잠긴다. 저장은 task_manager 가 받아들여야 반영된다.
